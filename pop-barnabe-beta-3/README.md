# Barnabé Ops — Beta 4 Visual

Sistema interno em Flask para POPs, rotinas e checklist local do estoque da Empadinhas Barnabé.

## Mudanças desta versão

- Visual mais moderno, claro e minimalista.
- Cores principais: branco, azul e detalhes em amarelo.
- Logo da Empadinhas Barnabé adicionada ao sistema.
- Header redesenhado.
- Painel do dia com card da marca.
- Cards, botões, checklist e guia de sabores com visual mais intuitivo.

## Como rodar

```bash
python -m pip install -r requirements.txt
python app.py
```

Depois abra:

```txt
http://127.0.0.1:5000
```

## Observação

O checklist continua usando localStorage. Isso significa que as tarefas marcadas ficam salvas no navegador do tablet/computador onde o sistema foi aberto.
